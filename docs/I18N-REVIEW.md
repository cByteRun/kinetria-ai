## Хранение предпочтений

`i18n/request.ts` выбирает проверенный `ru/en/kk` из `kinetria_locale`, иначе ru. `getTheme` читает `kinetria_theme`, по умолчанию dark. Server Actions записывают HttpOnly cookie на год, SameSite=Lax, path=/. Корневой layout задаёт lang и data-theme, NextIntlClientProvider получает конфигурацию того же запроса. URL и параметры карточки/фильтров не меняются. Нет глобального изменяемого locale.

Cookie выбран для SSR: localStorage недоступен при серверном рендере и потребовал бы второго источника истины и восстановления после загрузки. Предпочтения профиля БД и перенос между устройствами остаются следующим этапом. Категории уже читаются по выбранному языку из БД; остальные пользовательские данные не зависят от языка UI.

## Границы перевода

Переводятся интерфейс, справочные коды, даты, названия системных категорий/маршрутов и известные служебные шаблоны. Оригинальные обращения, предложения, теги, комментарии, решения, имена людей и пользовательские подразделения остаются без автоматического перевода. Синтетические примеры также сохраняют исходный текст. Это сохраняет смысл и доказательность истории. AI-черновик и сводка запрашиваются на выбранном языке; доступность внешней модели отдельная, в этом прогоне генерация не проверялась.

Редактор категорий требует миграцию `20261112095620_localized_categories.sql`. Она применена и зарегистрирована в **локальной** базе. Hosted-проект в рамках этой задачи не изменялся; перед выкладкой приложение и миграция должны попасть в одну целевую среду. Старый RPC сохранён для совместимости.
