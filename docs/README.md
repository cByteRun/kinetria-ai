IdeaRoute — внутренняя CRM для идей и сигналов бизнеса. Проект системы обратной связи для ГК «Модус Трейд» подготовлен к хакатону Pavlodar Hub. Начните с [README проекта](../README.md): ответы на три вопроса §6 ТЗ, проблема и ценность, три сквозных сценария, UX/UI, запуск и диагностика. Затем откройте бриф и продуктовую спецификацию.

Рабочий сценарий MVP использует Supabase для входа и хранения обращений и подключаемый локальный AI для черновика и сводки. Поддерживаются Ollama, OpenAI и Gemini. На Vercel можно явно включить Groq; Telegram/голосовой ввод настраиваются отдельно. Инструкция по подключению, импорту датасета и проверке в двух сессиях находится в [README проекта](../README.md).

## Исходные материалы
