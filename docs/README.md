# Документация Kinetria AI

Kinetria AI — внутренняя CRM для идей и сигналов бизнеса. Проект системы обратной связи для ГК «Модус Трейд» подготовлен к хакатону Pavlodar Hub. Начните с брифа, затем откройте продуктовую спецификацию и двухдневный план.

Рабочий сценарий MVP использует Supabase для входа и хранения обращений и подключаемый локальный AI для черновика и сводки. Поддерживаются Ollama, OpenAI и Gemini. В публичном демо на Vercel генерация отключена. Инструкция по подключению, импорту датасета и проверке в двух сессиях находится в [README проекта](../README.md).

## Исходные материалы

[Каталог TZ](TZ/) содержит исходные документы кейса.

- [Техническое задание](TZ/ТЗ_на_разработку_системы_обратной_связи_и_предложений_сотрудников.docx) — первичный источник требований к продукту. Описывает бизнес-задачу, роли, ожидаемые сценарии, границы решения и комплект результатов. В исходном файле указан статус проекта для согласования.
- [Датасет](TZ/Датасет.docx) — первичный источник синтетических примеров для разработки, проверки и демонстрации. Содержит 20 вымышленных обращений с типами, категориями, статусами, условными ответственными и примерами дальнейших действий.

Документы 00–08 переводят требования ТЗ в решения команды. При расхождении по требованиям сверяемся с ТЗ. Датасет используем для примеров и контрольных расчётов. Сроки подачи и регламент защиты уточняем у организатора.
