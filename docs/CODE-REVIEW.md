## Оставшиеся ограничения ревью

1. **P2 — размер выборки.** `components/request-workspace.tsx` получает карточки одним запросом без пагинации, счётчики оболочки делают аналогичный запрос. Если доступных строк больше серверного лимита Data API, реестр и агрегаты окажутся неполными. Текущая проверенная демобаза меньше лимита. Перед пилотом с большим объёмом нужны пагинация и агрегаты с RLS на сервере, а не увеличение клиентского набора без ограничений.
2. **P2 — время содержательного ответа.** `supabase/migrations/20261112005114_live_dashboard.sql:31` устанавливает `first_response_at` при выходе из `new`. Подпись «До рассмотрения» соответствует текущему поведению. Для KPI ответа автору потребуется отдельное событие/поле и пересмотр истории; исторические данные не переписывались.
3. **Продуктовая граница.** Общая категория и тег не подтверждают дубликат, причину или уникальное внедрение. Нет таблицы подтверждённых связей и счётчика уникальных авторов. Интерфейс не обещает автоматического слияния; исходные карточки, статусы и решения остаются отдельными.
4. **Локализация.** Новые подписи кабинетов преимущественно русские; полноценная EN/KK-локализация этих подписей ещё не выполнена.
