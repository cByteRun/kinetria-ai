# IdeaRoute · инструкция для жюри

## Откройте готовый проект

**Веб:** [https://kinetria-ai.vercel.app](https://kinetria-ai.vercel.app)  
**Выбор роли:** [https://kinetria-ai.vercel.app/login](https://kinetria-ai.vercel.app/login)  
**Telegram-бот:** [IdeaRoute](https://t.me/VoiceChatGpt_Custom_bot)

Скачивать код, устанавливать Docker, настраивать БД и вводить AI-ключи для просмотра не нужно. Приложение уже размещено на Vercel и подключено к общей базе с синтетическими демоданными. Экран входа предлагает готовые аккаунты. Демо не содержит закрытых данных ГК «Модус Трейд».

## Пять минут на проверку

1. Выберите **сотрудника**. Откройте «Новое обращение», заполните поля вручную или с AI, проверьте категорию, при необходимости приложите файл и нажмите «Зарегистрировать». Запомните R-номер.
2. В отдельном окне выберите **руководителя IT**, если выбрана категория «Каталог и данные», либо соответствующего владельца из предварительного маршрута. Откройте ту же карточку, возьмите на рассмотрение, запросите уточнение. Сотрудник отвечает внутри карточки. Руководитель фиксирует шаг и итог; сотрудник читает решение и отмечает ознакомление.
3. Выберите **администратора**: «Маршрутизация» → категория → руководитель → сохранить. Новые обращения этой категории получают выбранного владельца. Уже зарегистрированные карточки автоматически не переназначаются; при проверке восстановите исходное правило.
4. В реестре руководителя/администратора откройте Qvin по выбранной выборке. Для тем выберите похожие обращения, сгенерируйте тему и явно сохраните её; повторная загрузка сохраняет группу.
5. При желании выберите **клиента**: `/feedback` → приватный отзыв → модерация публичной копии/ответ рабочей ролью → поддержка опубликованной идеи сотрудником.

В README выделены **шесть основных сценариев**, а не исчерпывающий перечень функций. [Записи](DEMO_RECORDING.md) включают также отдельный пример изменения маршрутов администратором.

## Telegram: нужна только привязка профиля

В выбранном веб-аккаунте откройте «Справка» и получите одноразовую ссылку подключения. Перейдите по ней в [бота](https://t.me/VoiceChatGpt_Custom_bot) и нажмите Start. Ссылка связывает Telegram с выбранным профилем; простой переход по публичной ссылке на бота аккаунт не привязывает. Далее используйте `/help`, `/new`, `/list`, `/qvin` и другие действия своей роли. Настройки категорий и маршрутизации находятся в вебе.

При одновременной проверке используйте разные демопрофили и разные Telegram-аккаунты. Демопереключение ролей одного участника не является корпоративным SSO. Telegram необязателен для полного веб-цикла.

## Troubleshooting

| Что случилось | Что сделать |
|---|---|
| Не открывается ссылка | Используйте основной адрес выше, без адреса preview deployment; проверьте сеть и откройте `/login` |
| Не видно карточку | Проверьте роль и категорию: сотрудник видит своё, руководитель — своё направление, ответственный — назначения |
| Новая карточка без владельца | Администратор проверяет категорию и маршрут; карточка сохранена в резерве |
| Не сохраняется обращение | Проверьте обязательные поля и лимит 3 файлов по 1 МиБ. Сохраните текст; администратору передайте время и роль. Ошибка 13.11 была вызвана отсутствующей миграцией регистрации, а не введённым текстом |
| AI/голос временно недоступны | При лимите провайдера используйте ручную форму или текст: регистрация не зависит от генерации AI |
| Бот просит связать профиль | Откройте новую одноразовую ссылку именно из веб-справки нужного аккаунта и нажмите Start |
| Одноразовая ссылка истекла | Создайте новую в справке; срок действия — 10 минут |
| В Telegram уже занята демороль | Используйте другой свободный профиль; не перехватывайте профиль другого проверяющего |
| Старая кнопка отклонена | Откройте свежую карточку: могла измениться версия или назначенный владелец |
