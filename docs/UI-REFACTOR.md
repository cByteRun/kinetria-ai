# UI, бренд и права AI · 13.11.2026

Единственное название продукта — **IdeaRoute**. SVG-знак и надпись используются из `public/brand/`; белый логотип README сохраняет ту же геометрию.

## Изменения

- Общий `LogoMark` использует исходные `icon-light.svg`/`icon-dark.svg` из `brand-assets/variant-3-monogram-ir`; геометрия и цвета сохранены. Название IdeaRoute восстановлено в навигации, входе, лендинге, портале, футерах, переводах RU/EN/KK, метаданных и CSV. Публичный SVG и favicon синхронизированы.
- `roleDestination` по умолчанию открывает `overview` для employee, handler, manager, admin. Явное допустимое намерение перехода сохраняется. Клиент продолжает входить в `/feedback`. Смена демороли через вход использует тот же обработчик.
- Общий `canGenerateTopics` разрешает admin/manager/handler. API отвечает 401 без сессии и 403 для запрещённой роли. Выборка 2–200 уникальных UUID перечитывается через пользовательский Supabase-клиент с RLS; пропущенный/чужой ID отклоняет весь запрос.
- В верхнем тулбаре доступны промпт и последние 100/200 видимых обращений. Исходный отказ на 63 обращениях был HTTP 413 провайдера (8643 входных токена при лимите 7000), а не запрет администратора. Компактные ID и ограниченные выдержки снижают размер входа; результат преобразуется в исходные UUID и проходит проверку состава. Ключ кэша включает точную выборку, промпт и модель. Данные за пределами RLS не добавляются.
- Qvin больше не требует `origin` в старой схеме. Отсутствующая таблица `request_enrichments` (PGRST205/42P01) означает отсутствие дополнительных оценок, а не запрет анализа. Другие ошибки не скрываются. Вход Qvin также ограничен выдержками.
- Реестр не обёрнут дополнительной карточкой; устранён повтор заголовка. AI-панель находится перед канбаном. Высота доски вычисляется по фактической позиции в окне через ResizeObserver; вертикальная прокрутка остаётся внутри колонок, горизонтальная — только у доски с семью статусами. На узком экране ширина карточек сохраняется.
- Детали реальных обращений используют существующий модальный Drawer поверх списка/доски. Escape, кнопка закрытия и фон закрывают его с сохранением параметров фильтра и режима. Native dialog ограничивает фокус.
- Повторяющиеся темы представлены таблицей: тема/категория, число обращений, доля с отдельным progress, результаты, просрочки, переход. Метрики и мониторинг сохранены. Основной текст 14px, метаданные 12px, заголовки секций 18px/600; числа используют tabular-nums.

## Проверка

- `npx tsc --noEmit` и production-сборка `IDEAROUTE_BUILD_DIR=.next-ui-refactor-build npm run build` — пройдены.
- Браузер: employee/handler/manager/admin после входа попадают в `?view=overview`.
- Администратор: реальный запуск кнопкой и POST генерации по 63 доступным обращениям и промпту — HTTP 200, возвращён массив тем. Сотрудник: тот же endpoint — HTTP 403. Выборка из одного обращения — HTTP 400.
- Drawer открывается поверх канбана; Escape возвращает `mode=board`. AI-тулбар расположен выше доски. Доска заканчивается в пределах viewport.
- Повторяющиеся темы: ширины 320/390/768/1440, без переполнения страницы. Доска: 320/768/1440, светлый/тёмный режим, без переполнения страницы. Лендинг и вход: 320/1440, без переполнения.
- В проверенном основном сценарии нет browser pageerror.
- Воспроизводимый основной сценарий: `scripts/check-ui-refactor.mjs`; требуется Playwright, доступный Chromium и запущенный localhost. Пути можно передать через `PLAYWRIGHT_MODULE`, `PLAYWRIGHT_EXECUTABLE_PATH`, адрес через `P0_BASE_URL`.

## Границы

Прямой вызов того же сервиса с 200 синтетическими обращениями успешно вернул две темы и прошёл проверку ID.

В реальной БД доступно 63 обращения: полный живой прогон на 100/200 не заявляется. Сервер допускает 2–200; выдержки становятся короче на больших выборках, что ограничивает полноту смыслового анализа. Генерация не сохраняет тему автоматически: остаётся явное действие сохранения. Схема и production не изменялись этой итерацией. Повторный вызов Qvin после нескольких AI-прогонов вернул сообщение о недоступности AI; это отдельная ошибка провайдера, не отказ прав. Ранее Qvin ответил по выборке, но неверно пересчитал её размер; в payload добавлен точный snapshotCount. Повторная проверка точности ответа Qvin после этой правки ограничена доступностью провайдера.
